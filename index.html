Tujuan Website

Student Care dirancang sebagai contoh website sederhana untuk membantu pengguna mencatat dan menemukan data mahasiswa Bisnis Digital. Navigasi dibagi menjadi beberapa halaman agar fungsi setiap menu mudah dipahami.

Website ini merupakan prototipe lokal untuk latihan. Data tersimpan di browser yang digunakan, bukan di server kampus.
